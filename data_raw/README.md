# data_raw: 수동 수집 자료

```
data_raw/
├── README.md
├── fgn_share.csv          금감원 보도자료에서 뽑은 외국인 채권 보유 비중 (fss_fgn_share.py가 생성)
├── fss_fgn_share.py       fgn_share.csv 생성 스크립트
└── original/              받은 원본 그대로
    ├── krx_futures/       KRX 외국인 3년·10년 국채선물 순매수 (fut3_*, fut10_*, 20개)
    ├── krx_vkospi/        KRX VKOSPI (vkospi_*, 9개)
    └── fss/               금감원 보도자료 목록·추출 텍스트 (PDF·HWP 원본은 git 제외)
```

`code/01_collect_data.R`가 읽는 수동 파일이다. 파일이 없으면 해당 열은 NA로 채워지고 경고만 나온다.
`original/` 안의 KRX 파일은 받은 그대로(CP949) 두고, 직접 만드는 파일은 날짜 `YYYY-MM-DD`, UTF-8 csv로 저장한다. 기간은 **2009-01-01부터** 받는다(250일 z점수 계산용).

| 파일 | 열 | 내용 | 출처 |
|---|---|---|---|
| `original/krx_futures/fut3_YYYY.csv`, `fut10_YYYY.csv` | KRX 원본 그대로 | 외국인 3년·10년 국채선물 일별 순매수(계약 수, 매수 − 매도) | KRX 정보데이터시스템 → 파생상품 → 거래실적 → 투자자별 거래실적 (로그인 필요) |
| `original/krx_vkospi/vkospi_YYYY.csv` | KRX 원본 그대로 | VKOSPI(코스피 200 변동성지수) 일별 종가 | KRX 정보데이터시스템 → 지수 → 파생 및 기타지수 → 개별지수 시세 추이 (로그인 필요) |
| `fgn_share.csv` | `pub_date, ref_month, fgn_share, source` | 외국인 상장채권 보유 비중(%), 공표일 기준 | 금융감독원 「외국인 증권투자 동향」 월별 보도자료. `fss_fgn_share.py`로 자동 생성 |

## 국채선물 받는 법
- 조회 설정: 일별추이, **거래량**, 순매수, 상품구분 3년국채 선물(또는 10년국채 선물), 시장구분 **정규**
- KRX는 한 번에 2년까지만 조회된다. 구간별로 받아 `original/krx_futures/fut3_<시작연도>.csv`처럼 저장한다(예: `fut3_2009.csv` = 2009–2010).
- 열 이름과 인코딩(CP949)은 **바꾸지 않는다.** 수집 코드가 `original/` 아래(하위 폴더 포함)의 파일을 모두 읽어 이어 붙이고 `외국인 합계` 열을 쓴다. 구간이 겹치면 에러로 멈춘다.

## VKOSPI 받는 법
- 지수명 **코스피 200 변동성지수**, CSV. 국채선물과 같이 2년씩 받아 `original/krx_vkospi/vkospi_<시작연도>.csv`로 저장한다. 마지막 파일 `vkospi_2025.csv`는 2025-01-01부터 2026-11-13까지 들어 있다.
- 열: 일자, 종가, 대비, 등락률, 시가, 고가, 저가. 수집 코드는 `종가`만 쓴다(`대비`는 부호가 없다).
- **2019-04-10 값은 오류로 보고 NA 처리한다.** 시가 12.91인데 종가 30.40이고, 전날 12.67·다음 날 12.29다. 같은 날 KOSPI와 VIX는 거의 움직이지 않았다. 원본 파일은 고치지 않고 수집 코드에서 처리한다.
- 확인 결과: 한국 거래일 4,394일과 정확히 일치(빠진 날 없음). 2026년 평균 59로 매우 높지만 같은 기간 KOSPI 급등락과 맞는 실제 값이다.

## fgn_share 만드는 법
- `python3 data_raw/fss_fgn_share.py all`을 Final Project 폴더에서 실행한다. [금감원 보도자료 게시판](https://www.fss.or.kr/fss/bbs/B0000188/list.do?menuNo=200218)에서 「외국인 증권투자 동향」을 찾아 첨부파일을 `original/fss/`에 받고, 비중을 뽑아 `fgn_share.csv`를 쓴다.
- HWP 파일을 읽으려면 `hwp5html`(pip 패키지 `pyhwp`, `six`)이 필요하다. PDF 원본과 HWP는 약 250MB라 git에 올리지 않는다. 추출한 텍스트(`original/fss/*.txt`)와 목록(`index.csv`)은 올린다.
- 범위: 2010년 3월분(2010-04-12 공표)부터 2026년 9월분(2026-10-30 공표)까지 199개월, 빠진 달 없음. 2010년 1~2월분 보도자료는 게시판에 없어서 2010-04-09까지는 NA다.
- 값을 읽는 순서:
  1. 본문 표 「외국인 채권 (순)투자 및 보유 추이」의 기준월 행 마지막 값(비중). 2013년 9월분부터 있다(157개월).
  2. 표에 비중이 없는 2010–2013년 8월분은 요약 문장의 "상장채권 잔액 대비 X%", "전체 상장채권의 X%" 등에서 읽는다(42개월). `source` 열에 어느 쪽인지 적었다.
- 검증:
  - 표와 문장이 모두 있는 달끼리 비교하면 두 달만 다르다. 2026년 3월분은 표 11.6 vs 문장 11.5, 5월분은 표 11.7 vs 문장 11.9다. 표의 보유금액/상장잔액(323,799/2,795,476 = 11.58%, 333,586/2,840,601 = 11.74%)이 표 값과 맞아서 표 값을 쓴다.
  - 0.4%p 넘게 바뀐 달(2010-12, 2019-05, 2021-02, 2025-11, 2026-03)은 표의 보유금액과 상장잔액으로 다시 확인했다.
- 공표일은 게시판 등록일이다. 기준월 말일과 공표일 사이는 30~60일이다.

## 주의
- 순매수는 **외국인** 투자자 구분만 쓴다. KRX 파생상품의 투자자 분류는 현물과 다를 수 있으니 화면의 분류명을 그대로 기록해 둔다.
- `fgn_share`의 `pub_date`는 해당 월 통계가 **발표된 날**이다(기준월이 아니다). 분석에서는 발표일부터 다음 발표 전날까지 같은 값을 쓴다.
- 금통위·FOMC 날짜는 수동 파일이 필요 없다. 수집 코드가 한국은행·연준 홈페이지에서 직접 가져온다.
