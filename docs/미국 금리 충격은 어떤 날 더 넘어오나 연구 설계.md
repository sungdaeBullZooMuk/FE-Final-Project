# 미국 금리 충격은 어떤 날 더 넘어오나: 연구 설계

Nov 23, 2026 · @kim

**요지.** 미국 금리 변화의 약 30%가 다음 날 국고채로 넘어오고, 그 크기는 날마다 다르다. 어떤 조건에서 더 넘어오는지를 가리기 위해, 네 가지 조건마다 증폭(+)과 완충(−) 가설을 세워 어느 쪽이 맞는지 검정한다.

## 연구 요지

**연구 질문.** 간밤 미국 금리 충격이 다음 날 국고채로 더 세게 넘어오는 날은 어떤 조건일 때인가?

**데이터.** 2010-01-04 \~ 2026-10-30, 한국 거래일 쌍 4,140개. 국고채 3년·10년(← 미 2년·10년). 출처는 ECOS, FRED, 뉴욕 연은, KRX, 금융감독원.

| 기초 사실 | 결과 |
| --- | --- |
| 평균 전이 | 미 금리 1bp → 다음 날 3년물 0.29bp, 10년물 0.30bp (t 16.7, 19.2). 상승·하락 대칭 |
| 시기별 변화 | 250일 롤링 β가 0 \~ 0.6 사이에서 움직임 |
| 변동성 전이 | 미 충격이 클수록 다음 날 변동성 증가 (GARCH-X c: 10년 0.99, 3년 0.28) |
| 예측력 | 미 충격을 쓰면 표본외 R² 0.15 (3년), 0.19 (10년) |

**지금까지의 답 (1단계).** "불안하거나 외국인 포지션이 쌓이면 더 넘어온다"는 통념과 달리, 10년물에서는 두 조건 모두 전이를 **줄였다**. 3년물은 조건에 따른 차이가 없다.

**이번 단계의 과제.** 조건마다 증폭 논리와 완충 논리 중 무엇이 맞는지 가리고, 그날 충격의 성격이라는 조건을 더해 결과를 확인한다.

## 가설

조건 네 가지를 한 식에 넣어 경쟁시킨다. 각 조건에는 선행연구에 따른 증폭(+) 가설과 완충(−) 가설이 있고, 양측 검정으로 어느 쪽인지 판정한다.

| 가설 | 조건 (t일에 알려진 값) | 증폭 (+) | 완충 (−) | 주 만기 | 1단계 결과 |
| --- | --- | --- | --- | --- | --- |
| **H1 기대** | \|국고채 1년 − 기준금리\| | 국내 정책 기대가 불안정하면 외부 충격에 휩쓸린다 | 한은의 독자 경로가 뚜렷하면 국내 요인이 지배한다 | 3년 | 3년 0.010 (p 0.57), 10년 −0.024 (p 0.07) |
| **H2 수급** | 외국인 3년 선물 누적 순매수 (미 금리 상승일) | 쌓인 포지션이 청산되며 매도가 커진다 | 두터운 수요가 버틴다 | 10년 | −0.075 (Holm 0.022) → 완충 |
| **H3 위험** | log VIX | 신흥국은 위험에 민감해 더 흔들린다 | 위험회피 때 미 국채 움직임은 안전자산 쏠림이라 덜 넘어온다 | 10년 | −0.034 (Holm 0.044) → 완충 |
| **H4 충격 (추가)** | 그날 밤 충격의 성격: 미 금리와 주가가 반대 방향 = 통화정책형 | 긴축 신호는 한국의 정책 기대까지 움직여 더 넘어온다 | – | 3년, 10년 | 재계산 필요 |

- 계수는 조건이 1 표준편차 높을 때 전이 계수의 변화다. 기준 전이 계수는 3년 0.265, 10년 0.310이다.
- **주 만기:** 기대 경로는 정책금리에 가까운 3년물에서, 수급·위험 경로는 외국인 비중이 크고 기간프리미엄이 있는 10년물에서 강하다고 본다(한은 2023, 자본시장연구원 2023). 다른 만기는 비교용으로 보고한다.
- **H2 비대칭:** 완충이라면 효과는 상승일에만 있고 하락일에는 없어야 한다. 1단계 하락일 계수는 +0.034 (p 0.16)다.
- **변수:** H1\~H3의 조건 변수는 1단계에서 결과를 보기 전에 정한 그대로 쓴다.

### 원본 가설에서 바뀐 점

| 가설 | 원본 (1단계) | 바뀐 것 | 이유 (선행연구) |
| --- | --- | --- | --- |
| H1 기대 | 기대가 불안정하면 전이 확대(+). 만기 구분 없음 | 증폭 대 완충 경쟁 가설. 주 만기 3년 | 한은(2023): 중·단기물은 국내 통화정책이 지배 → 한은의 독자 경로가 뚜렷하면 미국을 덜 따를 수 있음(완충 논리). 기대 경로는 정책금리에 가까운 단기물에서 드러나야 함 |
| H2 수급 | 쌓인 포지션이 청산되며 상승일 전이 확대(+) | 증폭 대 완충 경쟁 가설 + 상승·하락 비대칭 검정. 주 만기 10년 | 자본시장연구원(2023): 외국인 선물 순매수는 금리 하락 요인이고 10년물에서 큼, 거래 비중 10년 53% → 두터운 수요가 버틸 수 있음(완충 논리) |
| H3 위험 | 위험이 클수록 전이 확대(+) | 증폭 대 완충 경쟁 가설 + 기간프리미엄 메커니즘 점검. 주 만기 10년 | Kalemli-Özcan(2019): 신흥국은 위험에 민감(증폭) 대 Miyajima 외(2012): 위험 악화 때 안전자산 쏠림(완충). Albagli 외(2019): 신흥국 파급은 기간프리미엄 경로 → 메커니즘을 분해로 확인 |
| H4 충격 | 없음 | 새로 추가. 그날 충격의 성격을 네 번째 조건으로 둔다 | Hoek 외(2022), Arteta 외(2022), KDI(2023): 긴축 신호로 오른 미 금리는 파급이 크고 성장 뉴스는 작음. 한은(2026): 동조화는 주로 정책기대 경로 |
| 공통 | 한 방향 예측 후 양측 검정 | 가설마다 두 방향을 문헌으로 명시 | 각 경로에 증폭과 완충 논리가 모두 문헌에 있어, 양측 검정의 근거를 구체화함. 원본 예측과 조정 시점은 보고서에 함께 밝힘 |

## 통계 모델

모든 모형은 교안(선형 시계열, 변동성, 예측 평가, 축소 추정) 범위 안에서 골랐다.

| 교안 단원 | 모형 | 쓰는 곳 |
| --- | --- | --- |
| 선형 모형, 가정 4 위반 → 강건 표준오차 | OLS + Newey–West(HAC, 시차 9) | 기본 모형, 가설 모형 |
| 단위근, 정상성 | ADF, KPSS → I(1) 조건은 250일 이동 z점수 | 전처리 |
| VAR | VAR(p), 그레인저 인과, 촘레스키 충격반응 | 전이 방향과 누적 반응 |
| 롤링 창 | 250일 롤링 OLS | 시기별 변화 |
| ARCH/GARCH | GARCH(1,1)-X, Student-t, QMLE | 변동성 전이 |
| 축소 추정 | LASSO, Elastic Net, 적응형 LASSO | 조건 선택 확인 |
| 예측 평가 | 1,000일 롤링 창 1일 앞 예측 | 표본외 비교 |

### 기본 모형

```latex
\Delta y_{t+1} = \alpha + \beta_0\, s_t + \rho\, \Delta y_t + \delta' D_t + \varepsilon_{t+1}
```

- Δy(t+1): 한국 t일 종가 → t+1일 종가의 국고채 금리 변화(bp)
- s(t): 한국 t일 마감 뒤 \~ t+1일 개장 전에 끝난 미국 거래일 금리 변화의 합(bp)
- D(t): 연휴 다음 날, 미국 휴장, FOMC, 금통위 더미

### 가설 모형 (네 조건 경쟁)

```latex
\Delta y_{t+1} = \alpha + \big(\beta_0 + \beta_1 G_t + \beta_3 V_t + \beta_4 MP_t\big)\, s_t + \beta_2^{+} F_t\, s_t^{+} + \beta_2^{-} F_t\, s_t^{-} + \gamma' z_t + \rho\, \Delta y_t + \delta' D_t + \theta' \mathrm{trend}_t + \varepsilon_{t+1}
```

| 기호 | 변수 | 검정하는 계수 |
| --- | --- | --- |
| G | \|kr1y\_gap\| (표준화) | H1: β₁ |
| F | fut3\_cum (250일 z) | H2: β₂⁺, 비대칭 β₂⁺ = β₂⁻ |
| V | log VIX (표준화) | H3: β₃ |
| MP | 미 금리 변화와 S&P500 수익률의 부호가 반대인 날 1 | H4: β₄ |
| s⁺, s⁻ | max(s, 0), min(s, 0) | – |
| z | G, F, V, MP의 수준 항 | – |
| trend | 추세, s × 추세 (없는 결과도 보고) | – |

### VAR

- z(t) = (s(t), Δy(t+1))′, 시차는 BIC로 선택
- 촘레스키 순서: 미국 먼저 (더 외생적인 변수 먼저)
- 한국 → 미국 그레인저 인과가 없으면 s를 외생 변수로 둔 OLS가 뒷받침된다
- 누적 충격반응(t+1\~t+5)으로 아시아 시간 거래에 따른 지연 반영을 본다

### GARCH-X

```latex
\sigma^2_{t+1} = \omega + a\, \varepsilon_t^2 + b\, \sigma_t^2 + c_m\, s_t^2 MP_t/100 + c_g\, s_t^2 (1 - MP_t)/100
```

평균식은 기본 모형이다. c\_m = c\_g로 묶으면 1단계 GARCH-X가 된다. 통화정책형 충격이 변동성도 더 키우는지(H4의 2차 적률 버전) 본다.

## 검정과 확인

### 검정

| 무엇을 | 검정 | 대상 |
| --- | --- | --- |
| 개별 상호작용 계수 | 양측 t 검정 (HAC) | H1 β₁, H2 β₂⁺, H3 β₃, H4 β₄ |
| H2 비대칭 | Wald(F) 검정 β₂⁺ = β₂⁻ | 10년 |
| 네 조건 전체 | 결합 Wald(F) 검정: 상호작용이 모두 0 | 3년, 10년 |
| 선형 가정 점검 | 5분위 상호작용, 최상위 = 최하위 분위 Wald | H1\~H3 |
| 전이 방향 | 그레인저 인과 (VAR) | 미국 ↔ 한국 |
| 변동성 | 우도비: c = 0, c\_m = c\_g | GARCH-X |
| 잔차 | Ljung–Box Q(10), ARCH LM(5), VIF | 모든 회귀 |

**다중검정.** 핵심 검정은 주 만기 기준 5개다: H1(3년), H2(10년), H3(10년), H4(3년), H4(10년). 이 5개에 Holm 보정을 하고, 나머지는 비교·보조로 표시한다.

### 확인: 표본외 예측

1,000거래일 롤링 창으로 t+1일 개장 직전(s(t) 관측 후)의 Δy를 예측한다.

| 모형 | 내용 |
| --- | --- |
| M0 | 0 (랜덤워크) |
| M1 | 기본 모형 |
| M2 | 1단계 조건부 모형 (H1\~H3) |
| M3 | LASSO |
| M4 | 가설 모형 (H1\~H4) |

| 비교 | 검정 |
| --- | --- |
| 중첩 모형 (M1 대 M2, M1 대 M4) | Clark–West (단측), Giacomini–White |
| 비중첩 모형 | Diebold–Mariano |
| 전체 (M0\~M4) | MCS (α = 0.10, Tmax), 공통 구간 |
| 변동성 예측 (GARCH 대 GARCH-X) | QLIKE 손실 + DM |

QLIKE는 금리 변화가 0bp인 날에도 정의되도록 log h + ε²/h 형태를 쓴다.

## 보조 분석과 견고성

### LASSO

LASSO는 p값을 주지 않으므로 가설 검정이 아니라 "데이터가 골라도 같은 조건이 나오는가"를 보는 데 쓴다.

| 용도 | 설정 | 판정 |
| --- | --- | --- |
| 조건 선택 | 적응형 LASSO, 후보 = 조건 13개 상호작용 + s × MP, 1,000일 롤링 창(20일 간격) | 선택 빈도 50% 이상 = 안정적. 1단계에서는 해당 항 없음 |
| H3 보강 (기존 결과) | 전체 표본 LASSO, Elastic Net(α = 0.5) | baa\_spread 선택: 3년 −0.026, 10년 −0.031 → 위험 완충과 같은 방향 |
| 표본외 | 일반 LASSO (M3) | MCS에서 비교 |

- 벌점은 상호작용 항에만 주고, 모든 후보는 표준화한다.
- 적응형 가중치는 1/|β̂\_Ridge|, γ = 1(Zou, 2006)로 둔다. 적응형 LASSO는 오라클 성질이 있다.
- λ는 BIC로 고르고, 시계열 CV(표본외 예측 오차)로 결과가 같은지 확인한다.

### 메커니즘 점검

| 가설 | 완충이 맞다면 | 보는 방법 |
| --- | --- | --- |
| H3 위험 | 안전자산 쏠림, 즉 기간프리미엄 부분에서 약해져야 한다 | 미 10년 충격을 기대 부분과 기간프리미엄 부분으로 나눠 VIX와 상호작용 (ACM·KW 둘 다 보고, 두 계수 동일성 Wald) |
| H2 수급 | 하락일에는 효과가 없어야 한다 | β₂⁺ = β₂⁻ Wald |
| H4 충격 | 정책 신호라면 단기물이 더 오르는 날도 더 넘어와야 한다 | MP 대신 FLAT(미 2년 변화 > 10년 변화) |

1단계 ACM 분해에서는 기간프리미엄 부분 × VIX가 −0.034 (p 0.005)였고, KW 분해에서는 +0.033 (p 0.50)이었다.

- 추세 통제 있음/없음
- 표본 분할: 2010\~2019 / 2020\~2026, 기간 더미 × s의 결합 F 검정(2013\~21 대 2022\~26)
- 극단값: |s| 상위 1% 제외, 1% 윈저화

## 한계와 할 일

### 한계

- 상관이지 인과가 아니다. 그레인저 인과는 예측력에 대한 검정이다.
- 충격의 성격(MP, FLAT)과 외국인 포지션(누적 순매수)은 대용치다.
- 기간프리미엄은 모형 추정치라 ACM과 KW의 결과가 다르다.
- 아시아 시간 거래 때문에 하루 전이가 작게 잡혔을 수 있다.
- 증폭·완충 경쟁 구도와 주 만기는 1단계 결과를 본 뒤 문헌으로 정리했다. 5년물과 표본외 결과가 약하면 탐색적 결과로 보고한다.

### 할 일

- [ ] MP 정의를 11-20 설명서와 맞춰 고정하고 가설 모형(H1\~H4)을 다시 추정한다
- [ ] 5년물 예측표를 팀이 확정한 뒤 데이터(ECOS, DGS5)를 모은다
- [ ] VAR, GARCH-X(c\_m, c\_g), 표본외 M4, 적응형 LASSO를 추정한다
- [ ] KRX 원자료에서 순매수 부호(+)를 확인한다
- [ ] VIX, fut3, S&P500이 t일 정보인지 극단적인 날을 손으로 대조한다
- [ ] 11-15 보고서와 11-20 설명서의 수치를 한 버전으로 통일한다
- [ ] 선행연구 원문을 확인한다
