# 강해진 전이는 남는가, 분산으로도 들어오는가 (설계 v9)

2026-11-28 · v8(docs/미국몫_분해설계.md)의 후속 설계. **이 문서는 6절의 새 분석을 돌리기 전에 커밋한다.**
v8의 가설·검정·결과(L1–L5)와 v6–v7의 결과는 바꾸지 않는다. 바꾸는 것은 보조 분석의 구성과 논문 배치다.

## 0. 왜 다시 짜나

- v8의 핵심 결과: 미국 몫이 커졌고(L1), 충격도 커졌지만(L2) 1bp당 전이 자체가 강해졌다(L3, L5 확인 못 함). 10년물은 전이 강화가 주된 요인이다.
- 지금 보조 분석 ①(시장 조건), ②(충격 성격), ③(변동성·VaR)은 처음 질문("어떤 날 더 넘어오나")에 대한 답이라, v8의 질문("왜 커졌나")과 이어지지 않는다.
- 교수님 기준 두 가지: **수업 모형을 써 볼 것**, **방법과 시도가 선행연구에 근거할 것**.
- 그래서 보조 분석을 v8 결과에서 바로 나오는 두 질문으로 바꾼다.
  - **M (지속성)**: 강해진 전이는 며칠 뒤에도 남는가, 되돌아가는가? "구조적 통합"이라는 v8 해석의 경제적 함의를 직접 확인한다. (VAR 충격반응, LN3; 직접 다단계 회귀, LN1 §15·LN2 I.5)
  - **G (분산 경로)**: v8에서 한국 고유 변동이 오히려 커졌다(L4, C_e < 0). 이 가운데 일부는 미국 충격이 다음 날 국고채 **변동성**을 키운 결과일 수 있다. 그렇다면 v8의 분산 비율은 미국 영향을 적게 잰 값이다. (GARCH-X, LN4 p.11)

## 2. 이미 본 것 (정직하게 기록)

- **전체 표본 직접 다단계 회귀 (v7 4-4)**: 누적 전이가 되돌아가지 않고 10일에 3년 0.42, 10년 0.39로 커진다.
- **전체 표본 VAR(시차 1) 충격반응 (v7 4-5)**: Cholesky 1 표준편차 충격 기준. 미 10년 → 국고 10년은 0일 0.89, 1일 0.22, 2일 −0.01. 미 2년 → 국고 3년은 0일 1.35, 1일 0.01.
- **전체 표본 GARCH-X (v7 4-8)**: c(s²/100) 3년 0.28 (se 0.20), 10년 0.99 (se 0.40).
- **v8 기술 분석을 기간 평균으로 묶은 값 (11-28 대화에서 계산)**:
  - GARCH 날마다의 미국 몫 평균: 3년 6.9% → 16.4%, 10년 15.5% → 21.2%.
  - 연도별 분해의 기간 평균 차이: 3년 충격 1.13 · 전이 0.44 · 국내 −0.57, 10년 0.30 · 0.84 · −0.42.
  - 2022–24년을 빼면 전이 기여가 3년 0.10, 10년 0.53.
- **아직 계산하지 않은 것**: 기간별(전기·후기) 충격반응, 기간별 직접 다단계 회귀, 기간별 GARCH-X와 분산 경로 몫. 6절의 가설은 이 숫자들에 대한 것이다.

## 3. M: 강해진 전이는 남는가 (확증)

**정의.** 기간 k(전기 2010-01-04 ~ 2019-12-31, 후기 2020-01-01 ~ 2026-10, v8과 같은 분할)마다 v8 5-2의 4변수 VAR(Δ미2년, Δ미10년, Δ국고3년, Δ국고10년, 행 정렬 같음, 시차 = 전체 표본 BIC = 1, 상수)를 따로 추정한다.
- 충격: 짝 만기의 미국 금리. 국고 3년은 미 2년, 국고 10년은 미 10년. 짝 미국 금리가 **Cholesky 순서 맨 앞**이 되도록 둔다(3년: 미2, 미10, 국3, 국10 / 10년: 미10, 미2, 국3, 국10). 짝 미국 금리의 오차가 그대로 충격이 되고, 다른 미국 금리는 같은 날 따라 움직일 수 있다.
- 크기: 충격 변수가 첫날 1bp 움직이도록 맞춘다(직교 충격반응 ÷ 충격 변수의 자기 첫날 반응). 그래서 v8의 β와 같은 단위다.
- **누적 반응** CIRF_k(h) = 국고채 반응의 0 ~ h−1 시점 합 (h = 1, …, 10일). h = 1이 다음 날 반응이다.
- **추가 반응** D_k = CIRF_k(10) − CIRF_k(1). 양수면 며칠에 걸쳐 더 넘어오고, 음수면 되돌아간다.

**가설.**

| 검정 | 귀무 / 대립 | 예측과 근거 |
|---|---|---|
| **M1** | ΔCIRF(10) = CIRF_후기(10) − CIRF_전기(10) ≤ 0 / > 0 | **+**. v8 L3에서 하루 전이가 강해졌고, 전체 표본 누적 전이는 되돌아가지 않았다. 통합이 깊어졌다면 10일 누적에서도 후기가 크다 |
| **M2** | ΔD = D_후기 − D_전기 = 0 / ≠ 0 | **방향 예측 없음(양측)**. 강해진 부분이 첫날 뒤에 더 커지는지 줄어드는지 |

- 만기 2개 × M1–M2 = **4개, Holm 보정**(v8의 8개와 별도 가족). 판정 규칙은 v8과 같다: Holm p < 0.05 "확인", 보정 전에만 p < 0.05 "보정 전 유의", 아니면 "확인 못 함".
- 추론: v8과 같은 이동 블록 부트스트랩(기간별로 행 블록, 블록 20일, 1,999회, seed 2026). 반복마다 두 기간 VAR를 다시 추정해 ΔCIRF(10), ΔD를 계산. p값과 95% 백분위 구간도 v8과 같은 방식.
- 확인 (Holm 밖, 보고만): 같은 양을 **직접 다단계 회귀**로 기간별 추정. [y(t+h) − y(t)]를 s(t), Δy(t), 더미 4개에 회귀(v7 4-4와 같은 식), HAC 시차 max(9, h). 두 기간 차이의 z = (b_후기 − b_전기) / √(se²_후기 + se²_전기) (두 기간 표본이 겹치지 않으므로 독립으로 둔다).
- 블록 길이 10·60일 견고성(보고만).

**해석 규칙 (미리 정함).**
- M1 확인 → "강해진 전이는 10일 뒤에도 남는다. 일시적 과민 반응이 아니라 연결이 깊어진 것이라는 v8 해석을 뒷받침한다."
- M1 확인 못 함 + M2 확인(ΔD < 0) → "강해진 것은 다음 날 반응이고, 며칠 안에 되돌아간다." v8 결론을 "다음 날 반응이 강해졌다"로 좁혀 쓴다(제목은 그대로, 초록과 결론에 한정어 추가).
- 둘 다 확인 못 함 → "10일 누적 차이는 불확실하다"로 쓰고 크기만 보고.
- VAR와 직접 다단계 회귀의 ΔCIRF(10) 부호가 다르면 "모형에 따라 다르다"고 밝힌다.
- 만기별로 결과가 다르면 만기별로 쓴다.

## 4. G: 미국 영향은 분산으로도 들어오는가 (기술, 보고만)

**정의.** 기간 k마다 v7 4-8의 GARCH-X를 따로 추정한다(평균식 = 기준 회귀, sGARCH(1,1), 분산식 외생항 c·s(t)²/100, Student t, c ∈ [0, 100], 시작값 0.1, solver hybrid. VIX 항은 v7 V1에서 확인되지 않았으므로 넣지 않는다).

  h(t+1) = ω_k + α_k e(t)² + b_k h(t) + c_k x(t),   x(t) = s(t)²/100

- 정상성(α + b < 1)이면 E[h] = (ω + c·E[x]) / (1 − α − b). 그래서 국고채 잔차 분산 가운데 **미국 충격이 변동성으로 만든 몫**은

  VS_k = c_k m_k / (ω_k + c_k m_k),   m_k = 기간 k의 x 평균

- 평균 경로와 분산 경로를 합한 미국 몫:

  VR*_k = (β_k² σ²_s,k + VS_k σ²_e,k) / (β_k² σ²_s,k + σ²_e,k)

  β, σ²_s, σ²_e는 v8 기간별 값을 그대로 쓴다. VR*_k ≥ VR_k이고, 차이가 분산 경로의 몫이다.
- 보고: 기간별 c, ω, α, b, α + b, c = 0 LR 검정(경계라 50:50 χ̄², 보정 없음), VS, VR, VR*. 표준화 잔차와 그 제곱의 Ljung–Box(LN4 p.20–21 진단).
- 부트스트랩은 하지 않는다(GARCH를 수천 번 다시 추정하는 비용). 그래서 확증이 아니라 기술 분석이다.

**해석 규칙 (미리 정함).**
- 두 기간 모두 c의 LR p < 0.05이고 VS_후기 > VS_전기 → "커진 한국 고유 변동의 일부는 미국 충격이 키운 변동성이다. v8의 분산 비율은 미국 영향의 하한이다."
- c가 한 기간에서만 유의 → 그 기간만 분산 경로가 있다고 쓰고, 기간 비교는 하지 않는다.
- 둘 다 유의하지 않음 → "분산 경로는 몫의 변화를 설명하지 않는다."
- α + b ≥ 0.999 이면 무조건 분산이 불안정하므로 VS를 보고하지 않고 c만 보고한다.

## 5. 하지 않는 것과 그 이유

- **충격 구성 분해**(통화정책형 날 비중 변화가 전이 강화를 설명하나): 검토했지만 뺀다. 분량과 일정(발표 12/9)을 생각하면 M, G 두 개가 한계이고, 수업 모형 활용은 M, G가 더 직접적이다. 결론의 "남은 과제"에 한 줄.
- **기간 프리미엄 분해**(ACM 기대 경로 대 기간 프리미엄): 충격 성격을 묻는 점에서 위와 겹치고, ACM 모형 설명 부담이 크다. "남은 과제"에 한 줄.
- 새 확증 검정을 GARCH 조건부 미국 몫(v8 기술 분석)에 붙이지 않는다. 결과를 이미 봤기 때문이다(2절).
