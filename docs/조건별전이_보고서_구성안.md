- 후보 답 ② **충격 자체의 성격** (3부, 문헌: Hoek, Kamin & Yoldas 2022)
- 결과: ①은 예측과 반대 방향, ②는 10년물에서 확인.

### 4 실증 방법 (2쪽)
**4-1 기준 모형과 상호작용 모형** — 식 2개
```
Δy(t+1) = α + β₀ s(t) + ρ Δy(t) + δ′D(t) + ε                              (1)
Δy(t+1) = α + (β₀ + β₁G + β₂F + β₃V) s(t) + γ′z(t) + ρΔy(t) + δ′D(t)
          [+ θ₁trend + θ₂ s·trend] + ε                                      (2)
```
- HAC(Newey–West, 시차 9) 한 줄 근거.
- 설정 A(trend 있음)와 B(없음)를 모두 사전 설정으로 보는 이유 2문장.

**4-2 검정 규칙** (이 절이 "데이터 마이닝 아님"을 보이는 곳)
- 1부: 양측, 6개 Holm, A·B 둘 다 통과해야 "유의". 만기별 결합 Wald χ²(3).
- 3부: N2·N3·N5·N7 8개를 미리 고정하고 Holm. N1은 효과를 본 뒤라 확증 검정에서 뺐다는 점을 밝힌다.
- 사전 등록은 **한두 문장만**: "가설과 검정 규칙을 결과보다 먼저 문서화하고 버전 기록(git)으로 시점을 남겼다. 결과를 본 뒤 추가한 분석은 별도로 표시했다."
- Holm은 교안 밖이라는 한 줄(통합안 1-3 끝).

**4-3 표본외 비교**
- 1,000일 롤링, M1(기준) / M2(조건) / M4(기준 + mon). Clark–West(중첩), GW(비중첩, 수업 `gwtest.R`).

**4-4 변동성 전이 (GARCH-X)**
- 분산식에 s² 항을 mon 여부로 나눠 c_m, c_g. Student-t, 부호 붙인 LR. 식 1개.

- 표 3: 1부 결과. 행 = P1–P3 × 3년·10년, 열 = 설정 A, B(계수, p, Holm p). 맨 아래 행에 결합 Wald p. 출처 `table3a_part1.csv`, `table3c_joint_wald.csv`. C·D는 표 6으로 보낸다.

  - 10년물 외국인 선물: 설정 의존(A만 통과).
  - 나머지: 기각 못 함. 3년물은 결합 Wald도 기각 못 함(A 0.13, B 0.22). 10년물 결합 Wald는 p < 0.0001.
- 표본외 한 문단(`table5_oos.csv`, M2 vs M1). 만기별로 다르게 쓴다:
  - 3년물: R²_OOS −1.6%, Clark–West p 0.28. 조건은 예측력을 더하지 않는다.

  - "조건은 예측력이 없다"로 뭉뚱그리지 않는다.

**5-3 반대 부호의 해석** (0.5쪽, 표 없음)
- "결과를 본 뒤의 해석"이라고 첫 문장에 밝힌다.
- 근거 세 개만: s⁺ = s⁻ 기각(10년물 p 0.009, 상승일에만 완충), R11 연도 내에서도 fut3 효과 유지(p 0.008), 공선성 아님(VIF 1.24 → 1.26).
- VIX는 **두 해석을 나란히**: ACM 분해는 기간 프리미엄 쪽, KW 분해는 기대 쪽에서 효과. 하나로 단정하지 않는다. 분해 표는 부록 A3.

**5-4 충격 성격** (2쪽) — 표 4
- 표 4: 3부 Holm 8개(`table8_part3_holm.csv`). 행 N2·N3·N5·N7, 열 3년·10년(통계량, p, Holm p).
- 문장 순서:
  1. 10년물에서 두 분류(mon, FLAT)가 같은 방향. 두 분류의 상관 0.01이라 서로 다른 근거.
  2. N5: mon을 더한 모형이 표본외에서 낫다(Holm 0.00005).
  3. N3: 변동성 전이도 방향은 같지만(c_m 1.77 대 c_g 0.67) 보정 후 유의하지 않음.

- N1(s × mon 회귀)은 본문 수치로 쓰되 "효과를 본 뒤 정한 검정이라 확증에 쓰지 않음"을 각주로.

### 7 결론 (1쪽, 4문단)
1. 핵심 메시지 반복 + 경제적 크기.
2. **함의**: 국고채 10년물의 미국발 위험을 볼 때, 미국 금리가 **왜** 움직였는지(통화정책 신호인지)를 함께 봐야 한다. 시장 조건만으로 전이 크기를 예상하는 것은 근거가 약하다.
3. **한계** 다섯 개(통합안 4-2): mon은 거친 일별 근사(하한 해석), 같은 날 주가·금리 동시 결정, 사전 가설 유의성의 설정 의존, 반대 부호는 사후 해석, 한 표본.
4. 후속 연구 한두 줄: 장중 고빈도 충격, 5년물·다른 나라.

## 4. 작성 규칙
