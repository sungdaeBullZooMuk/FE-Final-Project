# 국고채 금리에서 커진 미국의 몫: 충격이 커졌나, 전이가 커졌나 (설계 v8)

2026-11-26 · 주제 전환 설계. **이 문서는 v8의 새 분석(5절)을 돌리기 전에 커밋한다.**
1–4부(v6, v7)의 가설·검정·결과는 바꾸지 않고 새 논문의 한 부분으로 그대로 옮긴다.

## 0. 왜 주제를 트나

- v6–v7의 질문은 "미국 충격이 **어떤 날** 더 넘어오나"였다. 미리 정한 조건(정책 기대, 외국인 선물, VIX)은 전이를 키우지 않았고, 4부(수업 모형)의 확증 검정 8개도 모두 확인되지 않았다.
- 한편 기술 분석에서 국고채 변동 중 미국 충격의 몫이 2014년 5–7%에서 2026년 24–27%로 커졌다(4부 VAR 롤링 분산분해).
- 이 몫이 커지는 길은 셋이다. ① 미국 충격 자체가 커짐, ② 1bp당 전이(β)가 커짐, ③ 한국 고유 변동이 작아짐. **어느 쪽인지는 아직 계산하지 않았다.** 경제적 함의가 셋이 전혀 다르다(①이면 미국 변동성 국면의 문제, ②이면 시장 통합의 심화, ③이면 국내 요인의 약화).
- 이 질문은 수업 모형이 그대로 답한다: 분산분해(LN3 VAR), 조건부 분산(LN4 GARCH), 구조변화(LN1), 부트스트랩(수업 자료), 예측과 VaR(LN2, LN6).

## 2. 이미 본 것 (정직하게 기록)

새 분석 전에 이미 본 결과는 다음과 같다. 이 결과와 방향이 같은 검정은 "확인"으로만 부른다.

- R4(2010–19 / 2020–26 나눈 견고성)는 VIX 상호작용 계수만 봤고, 두 기간의 분산 비율·충격 분산·잔차 분산은 계산하지 않았다.

## 3. 정의

기준 회귀(기간 k = 전기 2010-01-04 ~ 2019-12-31, 후기 2020-01-01 ~ 2026-10, R4와 같은 분할):

  Δy(t+1) = α_k + β_k s(t) + ρ_k Δy(t) + δ_k′D(t) + e(t+1)

- 미국 충격 분산 σ²_s,k = 기간 k의 s(t) 분산.
- 한국 고유 분산 σ²_e,k = 기간 k 회귀 잔차 분산.
- **분산 비율** VR_k = β_k² σ²_s,k / (β_k² σ²_s,k + σ²_e,k). "미국 충격으로 설명되는 부분과 한국 고유 부분을 합한 변동 중 미국 몫"이다 (Bekaert and Harvey 1997, Ng 2000, Christiansen 2007의 분산 비율과 같은 정의).
- **로짓 분해 (정확한 덧셈)**:

  Δ logit VR = logit VR_후기 − logit VR_전기 = 2Δlog|β| + Δlog σ²_s − Δlog σ²_e

  - 충격 기여 C_s = Δlog σ²_s
  - 전이 기여 C_β = 2Δlog|β|
  - 국내 기여 C_e = −Δlog σ²_e (한국 고유 변동이 작아지면 +)

## 4. 가설과 검정

| 검정 | 귀무 / 대립 | 예측과 근거 |
|---|---|---|
| L1 (확인) | VR_후기 ≤ VR_전기 / VR_후기 > VR_전기 | **+**. 롤링 분산분해로 이미 봄. Holm에 넣지 않음 |
| **L2** | C_s ≤ 0 / C_s > 0 | **+**. 2022년 이후 연준 급속 인상기에 미국 국채 금리 변동성이 커졌다 |
| **L3** | C_β = 0 / C_β ≠ 0 | **방향 예측 없음(양측)**. 롤링 β가 단조 증가하지 않음 |
| **L4** | C_e = 0 / C_e ≠ 0 | **방향 예측 없음(양측)** |
| **L5** | C_s ≤ C_β / C_s > C_β | **+**. "미국 몫 증가는 주로 충격이 커진 탓이다" (핵심 질문) |

- 만기 2개(국고 3년 ← 미 2년, 국고 10년 ← 미 10년) × L2–L5 = **8개, Holm 보정**. 판정: Holm p < 0.05 "확인", 보정 전에만 p < 0.05 "보정 전 유의", 아니면 "확인 못 함".
- 추론: **이동 블록 부트스트랩**. 두 기간을 따로, 행(하루 쌍) 단위 블록으로 다시 뽑는다. 블록 길이 20일, 반복 1,999회, seed 2026. 각 반복에서 두 기간 회귀를 다시 추정해 C_s, C_β, C_e, L5 차이, VR을 계산.
  - p값은 부트스트랩 분포를 귀무가설(θ = 0) 쪽으로 옮겨 계산한다: 단측 p = (1 + #{θ* − θ̂ ≥ θ̂}) / (B + 1), 양측 p = (1 + #{|θ* − θ̂| ≥ |θ̂|}) / (B + 1). L5의 θ = C_s − C_β.
  - 95% 신뢰구간: 백분위.
- 블록 길이 견고성(보고만): 10일, 60일.

## 5. 새 분석 목록

1. **5-1 기간별 분산 비율과 분해 (확증)**: 3–4절. 표 하나(두 만기 × 전기·후기의 β, σ_s, σ_e, VR, 분해 기여와 p).
2. **5-2 VAR 분산분해 기간 비교 (보고만)**: 4부 VAR(같은 4변수, 같은 Cholesky 순서, 시차 1)을 두 기간에 따로 추정해 10일 분산분해 미국 몫 비교. 같은 블록 부트스트랩으로 차이의 신뢰구간.
3. **5-3 조건부 분산 비율 (기술, LN4)**: s(t)에 GARCH(1,1)-t → h_s(t). 국고채는 기준 평균식 + GARCH(1,1)-t → 잔차 분산 h_e(t+1). β는 연도별(s×연도). VR(t) = β_y² h_s(t) / (β_y² h_s(t) + h_e(t+1)). 연 평균과 월 평균을 그림으로. 같은 로짓 분해를 연도별로 그려 어느 요인이 언제 움직였는지 보인다.
4. **5-4 미국 충격 분산의 구조변화 (기술, LN1)**: log s² 평균에 sup-Wald(15% 트리밍, HAC). β의 구조변화(기존)와 시점 비교.
5. 블록 길이 견고성(10, 60일), 표본에서 2020년(코로나 급변기) 제외한 후기로 분해 다시 계산(보고만).

## 7. 결과 해석 규칙 (미리 정함)

- L5 확인 → "미국 몫 증가는 주로 미국 충격이 커진 탓이다. 1bp당 전이가 강해졌다는 근거는 (L3 결과에 따라) 약하다/있다."
- L5 확인 못 함 + L3 확인(C_β > 0) → "전이 자체가 강해졌다(통합 심화)".
- 둘 다 확인 못 함 → "몫은 커졌지만 원인을 하나로 가를 수 없다"로 쓰고, 기여 크기를 기술로만 보고.
- L1이 부트스트랩으로 확인되지 않으면(전기·후기 차이가 불확실) 제목의 "rising"을 바꾼다.
